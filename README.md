## 🌟 Vision for Recruiters

Monogram isn't just a clone; it's a technical demonstration of **modern mobile architecture**. It showcases proficiency in:
*   **State Management**: Real-time UI updates using Firebase streams.
*   **Performance**: Optimized ListViews and asset caching.
*   **UI/UX Mastery**: Custom Glassmorphic navigation and fluid animations.
*   **Scalable Backend**: Integrated multi-provider authentication and cloud storage.

---

## 🚀 Application Flow

Understanding the user journey through Monogram:

1.  **Onboarding**: User lands on an immersive `WelcomeScreen` -> Authenticates via `Login/Signup` or `Social Providers` (Google/Facebook).
2.  **Discovery (Home)**: Accesses the `HomeFeed` showing dynamic stories and a curated post feed.
3.  **Creation**: Use the central action button in the **Floating Dock** to access `AddPost` -> Select media -> Upload to Firebase Storage.
4.  **Socialize**: Browse `SearchScreen` for users -> Engage in real-time messaging via `ChatScreen`.
5.  **Personalize**: Manage identity through the `ProfileScreen`, featuring post grids and activity stats.

## ✨ Core Features

### 🎨 Design & Experience
*   **Glassmorphic Navigation**: A bespoke floating dock with real-time blur and haptic-inspired feedback.
*   **Adaptive Theme**: Native support for **System Dark & Light modes** with custom color schemes.
*   **Typography**: Premium branding using **Google Fonts (Lobster & Roboto)**.

### ⚙️ Technical Prowess
*   **Multi-Provider Auth**: Secure entry via Email/Password and integrated OAuth (Google/Facebook).
*   **Real-time Interaction**: Instant messaging and live feed updates using **Cloud Firestore**.
*   **Media Management**: High-speed image uploads and retrieval via **Firebase Cloud Storage**.
*   **Cloud Architecture**: Optimized database structure for low-latency search and profile indexing.
